## Result provenance

Each reported result should be traceable to:

1. the experiment configuration,
2. the random seed,
3. the raw observation/decision output,
4. the analysis script, and
5. the repository version used for the run.

Paper-level numbers must not be entered manually into this directory.
Results should be generated by the experiment and analysis scripts.
## Required output contract

A canonical run should produce at least:

```text
results/
└── canonical/
    ├── raw_decisions.csv
    ├── summary.csv
    └── run_metadata.json
