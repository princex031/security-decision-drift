## Experimental boundary

The public traffic dataset is used only as an external observation
source in the trace-grounded extension.

It does not provide the historical defender intervention ledger required
to identify intervention-induced observation changes directly.

Therefore:

- no defender history is fabricated;
- no causal intervention effect is claimed from the dataset alone;
- controlled simulation remains the primary causal test.
